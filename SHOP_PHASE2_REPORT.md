## 3. Нове јавне руте

`/prodavnica`, `/prodavnica/:slug`, `/korpa` користе lazy loaded Angular компоненте. `/porudzbina` није додата.

## 4. Каталог

`PublicShopApiService` чита постојећи `GET /shop/products`. Backend већ ограничава резултат на активне производе. Каталог чита све API странице, без pagination UI-ја, претраге, категорија или филтера. Приказ има 3/2/1 колону, на постојећим преломима 1080 и 720 px. Додати су тражени уводни текст, сезонски benefit и loading/error/empty стања.

## 5. ProductCard

Картица је семантички `article` са једним правим линком, доминантном фотографијом у односу 4:5, насловом, ценом и позивом за отварање. Користи постојећи ImageFallbackDirective. Највише један badge: РАСПРОДАТО → НОВО → ИСТАКНУТО.

Фаза 1 јавног API-ја враћа `isNew`, који backend израчунава из `newUntil` у тренутку захтева. Frontend користи тај резултат, без другог датума или дуплиране backend логике. Нов захтев након истека више не враћа НОВО; нема посебног тајмера за већ отворену картицу. Распродат активан производ остаје видљив и може се отворити.

## 6. Детаљ производа

Чита `GET /shop/products/:slug`. Desktop има две колоне, мобилни једну. Приказује назив, цену, опциону претходну цену, сезонски benefit, избор величине/количине, додавање и информације о плаћању и достави. Опис је испод главног дела и приказује backend HTML уз Angular санитизацију; нема заобилажења Angular заштите. Runtime SeoService добија одговарајући наслов/опис, без Product JSON-LD-а. Обрађени су loading, 404 и грешка са поновним покушајем.

## 7. Галерија

Главна фотографија је прва, затим gallery фотографије у редоследу који већ враћа API. Исти URL се не дуплира. Thumbnail дугмад мењају позицију активне слике; scroll догађај ажурира активно дугме. Нативно хоризонтално померање и CSS scroll-snap омогућавају swipe. Нема нове библиотеке. Без слике се користи постојећи грб.

## 8. Величине и количина

API већ враћа само активне варијанте. Величине нису хардкодоване. Недоступне су онемогућене и прецртане; SOLD_OUT производ не може да се дода. Покушај без изабране величине приказује „Изаберите величину.” Количина је 1–99, а сабирање исте величине у корпи не може прећи 99. Нема аутоматске промене залиха. Успешно додавање користи постојећи ToastService и ажурира број у header-у, без преусмеравања.

## 9. Homepage carousel

Захтев има `featured=true`, `limit=10`, `order=asc`. Backend редослед по `featuredOrder` се чува. Нема допуњавања неистакнутим производима. Празан резултат или грешка сакривају секцију. После производа је CTA картица „КОМПЛЕТНА КОЛЕКЦИЈА”, а испод „СВИ ПРОИЗВОДИ”. Оба линка воде у продавницу.

## 10. Позиција секције

Нови компонент је између `section#klub` и `section#uprava`. Ниједна постојећа секција није премештена. HomeComponent се користи и за `/kontakt`; нова Shop секција је на тој рути искључена.

## 11. Мобилни carousel

Видљиве су 3/2/1 картице. Користи `overflow-x`, scroll-snap, нативни swipe/trackpad и приступачне стрелице. Нема autoplay-а и нема пресретања вертикалног wheel догађаја. Стрелице и gallery померање поштују `prefers-reduced-motion`.

## 12. Навигација

Додат је линк „ПРОДАВНИЦА” у постојећи desktop/mobile мени, уз постојећи RouterLinkActive и затварање менија. Друге ставке и dropdown логика нису промењене.

## 13. Мобилна иконица корпе

Корпа је засебан линк у header grid-у, изван `.header-actions`, који се на телефону сакрива. На мобилном су бренд, корпа и hamburger у истом реду; отварање менија није услов за приступ корпи. Број представља збир количина. Постојеће понашање скривања целог header-а при скроловању остаје исто.

## 14. CartService

Користи праве Angular signals за ставке, количине, актуелне производе, збир, loading/error/notice. Додавање исте величине сабира количину; уклањање и промена количине одмах ажурирају стање и storage. Иницијализација из storage-а је тек у browser lifecycle-у, без SSR приступа `window`-у. Storage догађај синхронизује другу картицу прегледача. Блокиран storage оставља употребљиву меморијску корпу уз поруку.

## 15. localStorage

Кључ је `kmf_shop_cart`:

```json
{
  "version": 1,
  "items": [{ "variantId": "primer-varijante", "quantity": 2 }],
  "updatedAt": "2026-09-08T00:00:00.000Z"
}
```

Не чува цену, назив, попуст или личне податке. Валидација одбија неисправан JSON, непознату верзију, неодговарајући датум, дупле/неисправне идентификаторе и количине. Оштећена корпа се испразни уз обавештење. Заштитни максимум је 100 различитих ставки.

## 16. Освежавање корпе и новац

При уласку у `/korpa`, враћању фокуса/видљивости странице и ручном освежавању, сервис поново чита каталог и повезује минималне ставке по `variantId`. Не користи петоминутни memory cache постојећег PublicApiService-а, нити Angular HTTP transfer cache. Нова промена цене замењује претходну; позната промена у истој сесији приказује поруку. После reload-а приказује тренутну цену, пошто се стара намерно не чува.

BigInt аритметика чува целе паре. Јавни helper приказује `320000` као `3.200 RSD`, а `320050` као `3.200,50 RSD`. Збир не укључује доставу или сезонски попуст. Приказ је информативан; Фаза 3 треба да замени реконструкцију позивом backend quote endpoint-а и поново обрачуна износ при слању поруџбине.

## 17. Гранични случајеви и поручивање

Деактивиран производ/варијанта, обрисан идентификатор, недоступна величина и SOLD_OUT остају у корпи као проблематичне ставке које корисник може да уклони. Не приказује се привидно потпун збир ако постоји таква ставка. API грешка чува избор и сакрива збир до успешне провере. Касни одговор старијег refresh захтева не може да препише новије цене.

Checkout није имплементиран. Development приказ има disabled „НАСТАВИ НА ПОРУЧИВАЊЕ” са објашњењем; production приказ нема то дугме и јасно каже да поручивање још није доступно. Нема broken route, placeholder `/porudzbina` или sticky checkout CTA-а.

## 20. Затечени проблеми и ограничења

**Пре објављивања је потребан засебан routing/SEO корак:** садашња `.htaccess` правила дају HTTP 404 свим непознатим јавним адресама осим привремених News рута. Зато директно отварање/reload `/prodavnica`, `/prodavnica/:slug` и `/korpa` на том Apache hosting-у није подржано овом конфигурацијом. Руте су функционалне у Angular навигацији и у локалном SPA fallback окружењу. `.htaccess` није мењан, по изричитом захтеву. Минимална наредна опција је договорено додавање fallback правила само за ове руте, уз засебну SEO одлуку.

Остало што није мењано: SSR HttpClient/XHR упозорење о `withFetch`; недостајућа корена lint скрипта; постојећи bundle warning; глобални `overflow-x: hidden` и генерисана стрелица на `.btn` дугмадима. Backend декларише Node 22.x, док локална провера користи затечени Node 20.20.0. Backend није мењан нити поново покретан у овој фази. Фаза 1 миграција и доступан Product API остају предуслов стварних каталошких података.

Администрација, footer, постојеће секције, News SEO, `app.routes.server.ts`, `.htaccess`, sitemap логика и dependency верзије нису мењани. Runtime Shop текст намерно користи SR поља и ћирилицу и при EN/RU избору остатка сајта; постојећи i18n систем остаје нетакнут.

## 21. Фаза 3 — препоручени следећи кораци

6. Пре објављивања спровести засебно одобрен Shop routing/SEO корак и проверити стварни hosting/API.
